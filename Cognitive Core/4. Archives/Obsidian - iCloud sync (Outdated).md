Very straight forward :
- Create a vault form iPhone and use iCould as storage option
- install iCloud in Windows PC and sync in file explorer
- Open Obsidian and select open a new vault and navigate to the vault folder created in iCloud.

**Key Notes**
- while using iCloud vault in windows enable ‘download files locally’ option on obsidian vault folder in file explorer(right click on folder to see this option) to avoid creating multiple copies of the file that is in edit mode
