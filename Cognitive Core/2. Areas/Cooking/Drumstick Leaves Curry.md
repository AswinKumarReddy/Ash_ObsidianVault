### Ingredients:

- Drumstick leaves (They shrink a lot so have more if need more portions)
- Onion
- Tadka/Talimpu basics
	- Jeera / jilakar
	- Mustard / aavalu
	- Chana Dal  
	- Urad Dal
	- Curry Leave / Karivepaku
	- Red Chilly
- Salt
- Chilly Powder
- Dry Coconut power (Optional - Greatly Enhances tase)
- Peanut Chutney powder (Optional - Greatly Enhances tase)



### Procedure:

1. Take some oli (2 table spoons - adjust based on leaf qunatitiy) in kadai
2. Start with basic tadka
	1. Start with jeera and mustard
	2. Add Chanadal and Urad dal, let them be properly toasted for a crispy texture (they are done once they stop bubbling)
3. Add onions and sauté them for 2 mins (they should look redcued and sligthly golder)
