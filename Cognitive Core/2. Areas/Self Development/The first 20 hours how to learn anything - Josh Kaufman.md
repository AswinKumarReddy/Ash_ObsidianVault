# 🧠 Learn Anything in 20 Hours — Framework (Josh Kaufman)

## 🎯 Core Idea
- You don’t need 10,000 hours to get “good enough”
- ~20 hours of **deliberate practice** → from clueless → competent
- Biggest barrier = **emotional (feeling stupid), not intelligence**

---

## ⚙️ The 4-Step Framework

### 1. Deconstruct the Skill
Break the skill into smaller, learnable parts.

**How to Apply**
- Define a clear outcome:
  - e.g., “Play 3 songs smoothly”
- Identify **3–5 subskills max**
- Focus on **high-impact components first**

### 2. Learn Just Enough to Self-Correct
Avoid overconsumption. Learn only what helps you identify mistakes.
> Learn only the minimum theory required so that **when you practice, you can detect and fix your own mistakes without needing constant external help.**

**How to Apply**
- Limit research to **1–2 hours max**
- Use:
  - 1 primary course/resource
  - 1–2 supplementary sources
- Focus on:
  - What “good” looks like
  - Common mistakes

**Rule**
> If you're still consuming after Day 2 → you're procrastinating

---

### 3. Remove Practice Barriers
Reduce friction so starting is effortless.

**How to Apply**
- Pre-setup environment:
  - Tools ready
  - Workspace clean
- Eliminate distractions:
  - Phone on airplane mode
  - Block apps/websites
- Reduce activation energy:
  - Make starting **stupid easy**

**Checklist**
- [ ] Tools ready
- [ ] Environment set
- [ ] Distractions removed

---

### 4. Practice for 20 Hours (Pre-commit)
Consistency beats intensity.

**How to Apply**
- Commit upfront:
  - ~45–60 min/day for ~20–30 days
- Track progress:
  - Use timer/log
- Push through initial frustration

**Rule**
> Do NOT quit before completing first 5 hours

---

## ⚠️ Key Insight
- “Feeling stupid” = **progress signal**
- Most people quit in first 2–3 hours
